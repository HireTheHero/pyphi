Add `script/bench_phyid.py` — B7 ΦID integrated synergy diagnostic using the `phyid` package (installed from GitHub: Imperial-MIND-lab/integrated-info-decomp). Simulates a Markov chain from the network TPM, computes pairwise discrete ΦID (MMI redundancy, τ=1) for all N(N-1) ordered node pairs, and sums the `sts` (Syn→Syn) atoms as a partition-free proxy for IIT Φ. Key finding: ΦID_SYN ≈ 0 for both benchmark networks despite non-zero IIT Φ (1.33 and 0.83). Gaussian approximation gives NaN on binary data. ΦID is not a useful proxy for IIT 4.0 Φ on small discrete-binary systems; it is better suited for large N with near-Gaussian continuous dynamics.
